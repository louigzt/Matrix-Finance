# Matrix Finance 💚

Sistema de controle financeiro pessoal desenvolvido com HTML, CSS e JavaScript.

🌐 **[Acessar o Matrix Finance](https://matrixfinance-psi-lilac.vercel.app/)**

## Funcionalidades
- Registro de receitas e despesas
- Gráficos financeiros
- Filtros por período
- Edição e exclusão de movimentações
- Armazenamento local dos dados

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Chart.js
